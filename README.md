# JorgeFit AI v4.1

A no-cost, installable Progressive Web App for personalized workouts, active set logging, recovery estimates, body tracking, workout history, offline use, and local backup/restore.

## Publish on GitHub Pages

Upload all files and the `icons` folder to the root of your existing repository. Keep GitHub Pages set to `main` and `/(root)`. After upload, wait about 1–3 minutes, then refresh the live site.

## Install on iPhone

Open the live site in Safari, tap Share, choose **Add to Home Screen**, and tap **Add**.

## Important

Data is stored locally on the device. Use Progress → Backup → Export before changing phones or clearing browser data. The “AI” coach is an on-device workout-selection algorithm; it does not send health information to an external AI service.


## Body-fat estimator
The Progress screen includes a U.S. Navy circumference-method estimator. It supports male and female formulas and can place the estimated percentage directly into the measurement log.

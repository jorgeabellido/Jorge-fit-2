UPDATE YOUR EXISTING GITHUB REPOSITORY
1. Unzip JorgeFit_AI_v3.zip.
2. Open your JorgeFit-AI-v2 repository on GitHub.
3. Upload and replace:
   index.html
   styles.css
   app.js
   manifest.json
   service-worker.js
   icon.svg
4. Commit the changes.
5. Wait 1–3 minutes for GitHub Pages to update.
6. Open your existing app address in Safari.
7. If the old version appears, refresh Safari or remove and re-add the Home Screen icon.

FREE IPHONE INSTALLATION
Open the GitHub Pages address in Safari.
Tap Share > Add to Home Screen > Add.

Your workout information is stored on your iPhone. Export a backup regularly.
